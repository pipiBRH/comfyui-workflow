# comfyui-workflow

ComfyUI workflows and the scripts that run them.

| Folder | What it is |
|---|---|
| [`family-portrait/`](family-portrait/) | Qwen-Image 2.1 family portraits (全家福). Faces and body shapes follow the reference photos; outfits, scenes and poses are new. Includes a Colab CLI pipeline with an automatic face-likeness check. |

Photos, generated pictures, face data and keys are never committed (see `.gitignore`).
